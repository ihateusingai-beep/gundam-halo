## What landed (2026-06-12, this session)

### A1. Remove `cyber-wave-demo` route ✅
- `App.tsx:6,43` — removed `CyberWaveformDemo` import and route
  registration. The dev playground is no longer reachable from the
  public app. File `src/routes/cyber-wave-demo.tsx` is left on disk
  for git history; can be re-wired later as `import.meta.env.DEV`
  guarded route if needed.

### A2. `/projects/:id/memory` desktop route — FALSE ALARM ❌→ ✅
- Initial review claimed `CockpitLayout`'s routes omitted the memory
  page, causing 404. Re-read shows the route **is** already
  registered at `App.tsx:41` (desktop) and `App.tsx:30` (mobile).
  No change needed. Lesson: when reviewing route tables, diff
  both `<Routes>` blocks side-by-side, not just one.

### A3. Extract `formatRelative` to `lib/time.ts` ✅
- Created `src/lib/time.ts` with the canonical implementation.
- Removed duplicate copies from:
  - `components/gundam/MissionCard.tsx` (was lines 92-110)
  - `components/gundam/MissionSelect.tsx` (was lines 155-173)
  - `components/gundam/ProjectCard.tsx` (was lines 138-156)
- All three now import `{ formatRelative } from "@/lib/time"`.
- The review originally noted 2 duplicates; actually 3. Caught by
  grepping the whole `src/` tree before editing.

### A4. VoicePanel audio queue → sequential drain with sequenceId ✅
- `components/gundam/VoicePanel.tsx` — replaced the
  `isPlayingRef`-flag-based drain with a Promise-chain drain
  guarded by `playSeqRef` (sequenceId) and `drainingRef`
  (single-drain guard).
- New `playChunk()` helper returns a Promise that resolves on
  `onended` or `onerror`; drain loop awaits each.
- When `status.state` transitions to `ready` / `idle` / `error`
  (i.e. turn boundary or cancel), bump `playSeqRef` and clear the
  queue so any in-flight drain aborts early.
- Stale-frame race fix: two simultaneous binary frames no longer
  overlap, and a frame pushed during a `✕ Cancel` no longer
  plays after the cancel.
- `AudioContext` ref (`audioCtxRef`) is unused after the rewrite
  but kept on disk to avoid touching the import surface mid-sprint.

### A7. Version hardcode → build-time `APP_VERSION` ✅
- `vite.config.ts` — added `define.APP_VERSION` that reads
  `process.env.VITE_APP_VERSION` (preferred) → `npm_package_version`
  (default) → `"0.0.0-dev"` (fallback).
- `src/vite-env.d.ts` — added `declare const APP_VERSION: string`
  so tsc doesn't complain.
- `components/layout/CockpitLayout.tsx:129` —
  `v0.1.0` → `v{APP_VERSION}`.
- Build-verified: default build → `STANDBY"," · v","0.1.0"]`;
  with `VITE_APP_VERSION=0.1.3 pnpm build` → `STANDBY"," · v","0.1.3"]`.
